# Carzo Dubai

Static MVP for a Dubai car-sharing marketplace inspired by Turo's booking flow.

## Open locally

Open `index.html` in a browser.

## Included

- Search by Dubai location and dates
- Car cards with filters and sorting
- Booking detail dialog
- English/Arabic language toggle with RTL layout
- Light/dark theme toggle

## Render deploy

This repo includes a `carzo/` static publish directory because the current Render service is configured with `Publish directory: carzo`.
